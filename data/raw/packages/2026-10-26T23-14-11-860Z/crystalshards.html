    Getting started

    Add a dependency

    Declare it in shard.yml, then fetch it.

    dependencies:
  kemal:
    github: kemalcr/kemal
    version: ~> 1.6.0

    Install

    Resolves the tree and writes shard.lock.

    shards install

    Publish

    Tag a release and the registry indexes it.

    git tag -a v1.0.0 -m "Release"
git push --tags
